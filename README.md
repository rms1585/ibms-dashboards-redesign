# IBMS dashboards redesign

Static prototype of the two redesigned IBMS C&F portal screens (billing dashboard and operations dashboard), built on the Minimals tokens from the IBMS Figma file.

Open `index.html` in a browser, or use the live page. Switch screens with the pill at the bottom. Data shown is sample data.

## Option B

A second take that follows Minimals dashboard patterns more closely (left nav, plain cards, soft labels, timeline alerts). It lives at `option-b/` and on the live site at `/option-b/`.
